balise sémantique : les balises sémantiques se sont des balises qui structures la page html d'une manière clair <header></header> / <footer></footer> / <nav></nav> / <section></section> ...

           ###################################################################

types de balises : il existe des balses  d'ouverture et autre de fermeture par exemple  <p></p> par contre il y a des balise d'ouverture et la fermeture non comme  <img>

           #################################################################

 <!DOCTYPE html> declarer  dans le debut pour  un fichier html

         ######################################################################
  class  : class peut étre utilisée plusieure fois (on appelle class par .)
  id     : doit etre unique dans la page(on appelle id par #)

Integration d'un fichier CSS externe la balise <link> permet de relier une page HTML a un fichier CSS externe afin d'appliquer le style a la page 
 <link rel="stylesheet" href="style.css">(rel ="stylesheet" : indique le fichier lié est une feuille de style CSS)
                                         (href = "style.css" : indique le nom et l'eplacement du fichier CSS )
------> l'objectif est séparer le contenu HTML de la mise en forme CSS et faciliter la gestion du design de la page ------

 insertion  d'image : <img src="./img/Black White Minimalist Professional Initial Logo (1).png" > la balise img permet d'afficher une image .
 src  : indique le chemin ou le nom de l'image 
 alt(text alternatif)  : decrit l'image si elle ne peut pas etre affichée et améliore l'accessibilité

height : definir la hauteur  de l'image
width  : definir la largeur de l'image 
            ##############################################################

<div> : crée un bloc ou un conteneur (permet de regrouper et organiser les éléments)
---> utilisée avec DSS pour appliquer un style a un groupe d'element
            ###########################################################

<a href = "Accueil.html"> Accueil</a>
<a> : balise utilisée pour crée un lien 
href(hyertext reference) : indique la destination du lien.
Accueil   : texte visile et cliquable par l'utilisateur.
----> l'objectif c'est permettre a l'utilisatuer de naviguer entre les pages ou versd'autres ressources.

            ###########################################################

<nav> : définit une section contenant les liens de navigation
           ############################################################
<ul>  : crée une liste non ordonnée , généralement avec des puces(organiser plusieurs élements sous forme de liste)

            ###############################################################

<li> : elle représent un élément de liste (ajouter un element a une liste)
            ################################################################

<main> contient le contenu principal et unique de la page
---> l'objectif est organiser la structure de la page et identifier clairement som contenu principal
            #################################################################

<section> : définit une partie de la page ayant un thème ou un sujet précis 
---> organiser le contenu da la page en différentes parties thématiques

            #################################################################
<article> : représente un contenu qui peut etre lu ou utilisé indépendamment du rest de la page 

            ################################################################
<span>  : permet d'isoler une partie du contenu (Elle est généralement utilisée avec CSSvbpour modifier le style d'une partie du texte)
